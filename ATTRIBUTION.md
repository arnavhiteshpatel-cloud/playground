# Data and Model Attribution

OsteoQuant model weights and experiment results derived from third-party datasets carry the attribution required
by those datasets' licences. Any distributed model trained on these data must ship this notice (e.g. in the
application's About → Third-party notices) and its model card must list the source.

| Dataset | Creators / source | Licence | Used for | Attribution requirement |
|---|---|---|---|---|
| SPROUT dog forelimb micro-CT, Zenodo 10.5281/zenodo.24047383 (forelimb subset) | dataset authors as listed on the Zenodo record | CC-BY-4.0 | real-data segmentation, transfer and few-shot experiments (H, I, S2, S3); models `unet_dog_bone_real`, `s2v2_*`, `s3_*`, `unet_ssl_real_s0` | credit the creators, link the licence, indicate changes (×2 downsampling, binary bone label, evaluation band) |
| Ovine metatarsal distraction callus (Zeiss TXM), Zenodo 10.5281/zenodo.17255310 | dataset authors as listed on the Zenodo record | CC-BY-4.0 | ingestion, ROI detection, performance, sample report 2 | as above |
| Scanco IPL trabecular cubes, Zenodo 10.5281/zenodo.11061947 | dataset authors as listed on the Zenodo record | CC-BY-4.0 | morphometry agreement (Experiment G) | as above |
| Mouse OA knee (Kitware), Zenodo 10.5281/zenodo.3909552 | dataset authors as listed on the Zenodo record | CC-BY-4.0 | DICOM ingestion; unlabelled pretraining (S3) | as above |
| NuInsSeg, Zenodo 10.5281/zenodo.10518968 | dataset authors as listed on the Zenodo record | see record (verify before any commercial use) | histology nuclei evaluation only (no shipped model) | as per record |

Exact creator names and citations are in `DATASET_REGISTRY.md` / `docs/research/` and on each record; copy them
verbatim into the shipped notice when a model derived from the dataset is distributed. Synthetic phantoms are
generated by this project and carry no third-party obligation.
