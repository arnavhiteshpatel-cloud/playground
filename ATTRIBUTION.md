# Data and Model Attribution

OsteoQuant model weights and experiment results derived from third-party datasets carry the attribution required
by those datasets' licences. Any distributed model trained on these data must ship this notice (e.g. in the
application's About → Third-party notices) and its model card must list the source. Creators, titles and years below
were copied from each Zenodo record's metadata (retrieved 2026-11-27 through the public Zenodo records API).

CC-BY-4.0 §3(a)(1) requires, in the shared material: the creators, a copyright notice if supplied, the licence
(https://creativecommons.org/licenses/by/4.0/), a link to the material, and an indication of modifications. The
"Changes made" column states the modifications inline.

**Models and experiments listed earlier but not in the registry.** Earlier versions of this file named models
`s2v2_*`, `s3_*` and `unet_ssl_real_s0` and an experiment "S3". They are not in `models/registry.json` and are not
distributed; they belong to the synthetic-to-real and self-supervised campaigns (S2/S3), which have not completed.
If any such model is registered, add a row here first.

**Registry fields.** Every entry in `models/registry.json` derived from these data carries the dataset DOI, SPDX
licence id, creators and attribution text (`dataset_doi`, `dataset_licence_spdx`, `dataset_creators`, `attribution`;
added for `unet_dog_bone_real`, `unet_synth_ft_dog_k1`, `unet_synth_ft_dog_k3`). Copy the `attribution` text into any
shipped notice. No model is shipped in the desktop bundle.

Synthetic phantoms are generated by this project and carry no third-party obligation.
