Welcome to Facial Recovery Monitor

A local, privacy-conscious desktop app for tracking facial movement, symptoms and recovery progress after facial nerve conditions.

Research prototype — not a medical device. Measurements are experimental and not clinically validated. It does not diagnose, rate recovery or recommend treatment.

Start the app

Your computerDo this
Windows 10/11Double-click START_WINDOWS.bat. If “Windows protected your PC” appears: More info → Run anyway. Press Y if asked to install Python.
MacRight-click START_MAC.command → Open → Open (first time only). If Python is missing its installer opens — install it, then press Return in the Terminal window.
LinuxRun ./start_linux.sh in a terminal.

The first start takes 1–3 minutes (installs everything from this folder — no internet needed on Windows and Apple-silicon Macs). Later starts take seconds.
