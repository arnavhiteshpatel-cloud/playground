# Defects found by QA (Gen-2 test campaign)

Each row lists the defect, how to reproduce it, the fix and the regression test. Severity uses the
same scale as the security review (critical, high, medium, low, info). "Assigned to lead" means
the defect is in a module QA must not edit. Each such row has a failing test marked
`xfail(strict=True)` where a test can express it.

Status on 2026-11-27: 25 defects. 21 are fixed with regression tests. 4 are assigned to the lead
(QA-022 to QA-025). There are also 6 observations about ambiguous expected behaviour, which were
documented and not changed.

## Observations: expected behaviour ambiguous; documented, not changed

| ID | Area | Observation |
|---|---|---|
| OBS-01 | `segment/metrics` | Dice and IoU of two empty masks are NaN, and HD95 of an empty mask is NaN. Some frameworks define Dice(∅,∅) = 1. The current convention excludes such classes from `mean_dice`. Tested as is. |
| OBS-02 | `stats.lins_ccc` | Uses sample (n−1) moments. Lin (1989) defines the estimator with 1/n moments, so small-n values differ: [1,2,3] vs [2,3,4] gives 0.667 against 0.571. The two converge for large n (tested at n = 5000). Decide and document which is intended. |
| OBS-03 | `morphometry.surface_area_mm2` | BS includes surfaces created where the VOI cuts the structure. For 24×24-voxel plates BS/BV = 64/mm against 50/mm for infinite plates. Marching cubes on a binary sphere over-estimates area by about 8.5 %. These follow from the documented method; tested with tolerances. |
| OBS-04 | `morphometry.local_thickness` | Confirmed the documented bias: exact for even voxel thicknesses and +1 voxel for odd. Thickness scales exactly with voxel size and is invariant to permutation and translation (property tests). |
| OBS-05 | `qc.run_qc` | An all-zero (blank) volume *with* valid spacing gets only `warn` (blank slices), so the verdict is "review" rather than "unsuitable". Consider making an all-blank or constant volume a deterministic fail. |
| OBS-06 | `stats.icc` | Assumes no missing values. NaNs propagate to a NaN ICC, now labelled "undefined" (QA-014). No pairwise deletion is done. |
